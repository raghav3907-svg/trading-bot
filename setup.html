WORKSPACE SETUP

Start with
the sandbox.

Keep credentials on the server, use testnet first, and bring the dashboard online in a few deliberate steps.

01

Create testnet keys

Use the Binance Futures Testnet account to create an HMAC-SHA256 API key and secret. Keep them private and scoped to testnet.

02

Configure the backend

Copy the environment template to .env, then set BINANCE_API_KEY, BINANCE_API_SECRET, and FLASK_SECRET_KEY.

03

Run locally

Install the requirements and start the Flask app. The dashboard will be available at 127.0.0.1:5000.

pip install -r requirements.txt
python app.py
04

Deploy securely

Deploy the Python backend on Render or another server, and add environment variables in its private settings. This static site never stores keys.

!

Testnet only

Orders can change your testnet account state. Check symbols, quantities, and prices before confirming. Never paste production credentials into this preview.
